# Easy Item Dump

Minecraft Bedrock resource pack. Buttons on container screens move items in bulk between your inventory and the container, or drop them on the ground.

Chests, barrels, shulkers, ender chests, hoppers, dispensers, droppers, crafters, and data-driven containers are included. Requires Bedrock 1.26.50 or newer.
